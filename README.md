# 🌤️🔮 오늘 뭐 먹지?

> 오늘 날씨와 나의 운세를 함께 분석해 딱 맞는 메뉴를 추천해드리는 실용 도구.

**▶ 지금 바로 사용** → [https://mindweaver74.github.io/weather-menu](https://mindweaver74.github.io/weather-menu)

---

## 🎯 주요 기능

- 📍 **위치 자동 감지** — GPS로 현재 위치 날씨를 자동으로 불러와요
- 🌡️ **실시간 날씨** — 기온·체감온도·습도·바람·구름 표시
- 🔮 **오늘의 운세** — 생년월일로 총운·금전·건강·애정운 계산
- 🌙 **음력 지원** — 음력 생년월일 입력 시 양력으로 자동 변환 (1940~2020년)
- 🍽️ **날씨 + 운세 통합 추천** — 두 가지 요소를 점수화해 딱 맞는 메뉴 4가지 추천
- 🎲 **다른 메뉴 추천받기** — 버튼 한 번으로 새로운 4가지 추천
- 🌟 **날씨+운세 최적 뱃지** — 둘 다 맞는 메뉴에 금색 강조 표시

---

## 🌈 날씨 + 운세 조합 추천 예시

| 날씨 | 운세 | 추천 예시 |
|------|------|-----------|
| ☀️ 더움 | 금전운 좋음 | 회·초밥·스테이크 (특별식) |
| ☀️ 더움 | 건강운 낮음 | 삼계탕·콩국수 (보양식) |
| 🌧️ 비 | 애정운 좋음 | 파전+막걸리·삼겹살 (함께!) |
| 🌧️ 비 | 금전운 낮음 | 된장찌개·라면·칼국수 (가성비) |
| 🥶 추움 | 건강운 낮음 | 갈비탕·설렁탕·삼계탕 |
| ❄️ 눈 | 총운 좋음 | 전골·샤부샤부 (특별하게) |
| ☁️ 흐림 | 금전운 낮음 | 짜장면·도시락·김치찌개 |

## 🔮 운세 기반 메뉴 연결

| 운세 | 추천 방향 |
|------|----------|
| 총운 좋음 (70+) | 평소 먹고 싶었던 특별 메뉴 도전! |
| 금전운 좋음 (70+) | 스테이크·초밥·회 등 고급 메뉴 |
| 금전운 낮음 (-50) | 라면·도시락·국밥 등 가성비 메뉴 |
| 건강운 낮음 (-50) | 삼계탕·갈비탕·순두부찌개 보양식 |
| 애정운 좋음 (70+) | 삼겹살·피자·샤부샤부 함께 먹기 좋은 메뉴 |

## 🌙 음력 생년월일 지원

- 입력란 아래 **🌙 음력 생년월일** 체크박스 선택
- 음력 날짜 입력 시 양력으로 자동 변환 후 운세 계산
- 변환된 양력 날짜를 실시간으로 표시
- 지원 범위: **1940~2020년** (윤달 포함)
- 범위 밖이면 원본 날짜 그대로 사용

## 🛠️ 사용 기술

| 항목 | 내용 |
|------|------|
| 날씨 API | [Open-Meteo](https://open-meteo.com/) — 무료, API 키 불필요 |
| 위치 | 브라우저 Geolocation API |
| 역지오코딩 | [Nominatim (OpenStreetMap)](https://nominatim.org/) |
| 음력 변환 | 자체 구현 (1940~2020 데이터 내장) |
| 운세 계산 | 생년월일 + 오늘 날짜 기반 해시 알고리즘 |
