# 🌤️ 오늘 뭐 먹지?

> 현재 날씨를 자동으로 확인하고, 날씨에 딱 맞는 메뉴를 추천해드리는 실용 도구.

**▶ 지금 바로 사용** → [https://mindweaver74.github.io/weather-menu](https://mindweaver74.github.io/weather-menu)

---

## 🎯 주요 기능

- 📍 **위치 자동 감지** — GPS로 현재 위치 날씨를 자동으로 불러와요
- 🌡️ **실시간 날씨** — 기온·체감온도·습도·바람·구름 표시
- 🍽️ **날씨 맞춤 메뉴 4가지** — 날씨와 기온을 분석해 딱 맞는 메뉴 추천
- 🎲 **다른 메뉴 추천받기** — 버튼 한 번으로 새로운 4가지 추천
- 💬 **날씨 멘트** — 오늘 날씨에 어울리는 한마디

---

## 🌈 날씨별 추천 메뉴

| 날씨 | 기준 | 추천 메뉴 예시 |
|------|------|--------------|
| ☀️ 더움 | 25°C 이상 | 냉면, 초밥, 샐러드, 아이스크림, 콩국수 |
| 🌤️ 선선 | 15~25°C | 파스타, 피자, 버거, 스테이크, 비빔밥 |
| 🥶 추움 | 15°C 미만 | 부대찌개, 삼겹살, 라면, 순두부찌개, 갈비탕 |
| 🌧️ 비 | 비 예보 | 파전+막걸리, 칼국수, 짬뽕, 치킨, 육개장 |
| ❄️ 눈 | 눈 예보 | 어묵탕, 전골, 감자탕, 설렁탕, 호떡 |
| ☁️ 흐림 | 흐린 날 | 짜장면, 돈가스, 카레, 쌀국수, 도시락 |

## 🛠️ 사용 기술

| 항목 | 내용 |
|------|------|
| 날씨 API | [Open-Meteo](https://open-meteo.com/) — 무료, API 키 불필요 |
| 위치 | 브라우저 Geolocation API |
| 역지오코딩 | [Nominatim (OpenStreetMap)](https://nominatim.org/) |
| 날씨 기준 | WMO Weather Code 표준 |
